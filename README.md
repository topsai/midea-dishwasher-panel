# 美的洗碗机局域网 Python 面板

通过 TCP 直接连接美的 V3 洗碗机，使用 Tkinter 展示状态并控制设备。运行时不依赖 中转服务 或美居云服务；首次配对需要提供有效的设备 Token 和 Key。

## 功能

- 展示协议库解析的 24 个参数，每 2 秒刷新，可手动刷新及重连。
- 控制电源、童锁、保管。
- 选择洗涤模式并确认启动。选择下拉列表本身不会发送命令。
- 显示原始字段和值、连接状态及操作反馈。
- 连接异常时禁用控制，并标注读数可能过期；失败操作不会自动重发。

模式列表来自通用协议，尚未在 7600V1E0 上逐项验证，只应选择机型支持的模式。暂停、预约、独立烘干／紫外控制、盐和亮碟剂档位设置未在当前协议库实现。

部分通用字段由协议库初始化为默认值，不代表机型支持该功能。发送命令不等同于设备已执行，应查看设备实际返回状态。

## 安装和运行

需要 Python 3.11+（本机实测 Python 3.14），Python 需包含 Tkinter。电脑与洗碗机须在同一局域网。

1. 将 `dishwasher.example.json` 复制为 `dishwasher.json`。
2. 填写实际设备的 ID、IP、Token、Key、型号及协议参数。V3 常用端口为 6444。已有 Midea AC LAN 配置时可从其设备配置中获取这些值。
3. Windows 双击 `start_panel.bat`。首次运行会自动创建本目录 `.venv` 并安装依赖，需要互联网连接。

也可在项目目录中执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe dishwasher_gui.py
```

Linux/macOS 使用虚拟环境中的 Python 执行相同脚本；Tkinter 可能需要通过系统包管理器单独安装。

只读温度：

```powershell
.\.venv\Scripts\python.exe read_temperature.py
```

Windows 也可双击 `read_temperature.bat`。

### 保管状态说明

“保管功能”是开关，“保管当前运行”是当前动作，两者独立。保管开启时，当前动作可以为“当前未运行”；这不表示保管功能已关闭。控制区同时显示当前动作和保管剩余小时。

### 桌面页面导航

默认打开主页，展示缺水、保管及剩余时间、电源及运行状态、门状态，以及洗涤启动和保管控制。右上角齿轮菜单进入“状态、控制、设备”三个子页面；全部参数集中在状态页，电源开关与连接状态和更新时间并排位于主页独立的白色圆角连接栏，童锁按钮位于控制页，设备信息、重连及操作记录位于设备页。子页面可点击“返回主页”或按 Esc 返回，页面切换保留模式选择并持续更新数据。

自动刷新间隔为2秒；Python的手动刷新和重连入口位于设备子页面。

两个版本的主页均无手动刷新/重连按钮；这些入口保留在设备页。

桌面状态卡片使用独立圆角背景和间距：正常/开启浅绿、缺水浅红、门打开浅橙、关闭状态浅蓝，未知或断线浅灰，与Android颜色规则一致。

温度卡片低于35℃为蓝色，35–50℃为橙色，高于50℃为红色；洗涤阶段空闲为蓝色，其他已上报阶段为橙色。文字与浅色背景同步，未知/断线为灰色。
# 配对与恢复设置（1.1.0）

Android 与 Python 均在齿轮菜单 → 设备页提供：局域网搜索、修改地址并重连、验证当前连接、美居账号登录获取/更新密钥、导入配置、导出备份。

先在官方美居 App 给洗碗机配网并绑定个人账号，再连接同一家庭 Wi-Fi。搜索并选择设备后输入账号密码；也可为当前配置更新密钥。当前仅支持 7600V1E0 / E1 / V3 / subtype 3，其他型号显示不支持。云端使用 Meiju 新版 v2 获取密钥接口，失败时兼容尝试旧接口。验证码登录未实现，云端接口是否允许此账号获取密钥仍取决于美居服务。

新密钥、导入配置与修改地址都先完成局域网认证和状态读取，再保存。失败时保留原配置，验证不会发送洗涤、电源或保管控制。美居密码不保存；安卓配对配置由 Keystore 加密，Python 保存在同目录 dishwasher.json。导出 JSON 备份含 Token/Key，应妥善保存，勿公开分享。无需 中转服务。

Python 首次启动没有 dishwasher.json 时会打开界面，可从设备页配置。需保留 dishwasher_gui.py、dishwasher_settings.py 和 dishwasher_pairing.py 在同一目录。

已验证手机实际搜索及现有密钥认证/读取、电脑指定 IP 搜索及认证。美居真实账号登录尚待用户在界面验证；自动测试验证签名、请求格式、失败保护与配置备份，不等于云端实测成功。
