# 验证范围

## 自动化检查

- Python：24 项测试，覆盖状态解析、颜色规则、导航、配对校验、失败时保留配置、切换设备后拒绝旧状态，以及源码／EXE 配置路径。
- Android：26 项单元测试，覆盖 E1/V3 报文、加密认证、配置解析、控制白名单、配对签名及失败保护。
- Android debug APK 构建和 lint 通过，无 lint 错误。协议发现流程中的 ECB 警告来自设备协议要求，不能任意替换算法。
- Windows x64 EXE 完成启动和配置路径验证；源码 ZIP 与 EXE ZIP 使用文件白名单打包。

测试命令见 [Android 开发说明](README.md)、[桌面打包说明](../desktop/README.md) 和 [项目首页](../README.md#开发与验证)。

## 实机验证

已在 Android 12、Android 15 手机上完成部分界面与连接验收。1.1.0 验证了设备页入口、局域网搜索、使用已有凭据认证及状态读取。Windows 桌面版也完成已有凭据的连接与读取。

自动化验收不主动启动真实洗涤，不切换实际电源、保管或童锁。控制报文测试通过不等于每一种模式都已在机器上执行验证；请只使用洗碗机实际支持的程序。

真实美居账号登录及获取新密钥尚未完成实测。当前验证包括模拟服务、签名和请求格式对照、失败保护，不应理解为所有账号均可成功配对。验证码登录暂不支持。
